# Litematica Format Converter

A high-performance utility and companion mod for Minecraft 1.21.4 that enables seamless bidirectional schematic format conversion between WorldEdit `.schem`, Sponge Schematic format, legacy MCEdit `.schematic`, NBT Structure format, and Litematica `.litematic`.

## Features

- **Universal Format Conversion**: Convert schematic files effortlessly between all major Minecraft schematic standards.
- **Palette & Block State Remapping**: Accurate bidirectional block state and block entity conversion.
- **CLI & In-Game Utilities**: Robust data structures supporting automated batch processing and programmatic conversion.
